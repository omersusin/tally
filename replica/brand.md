# Brand — Tally
Angle: for walkers who want an honest count — offline, no ads, no account, widget that works.

## Name
Winner: **Tally** (short, spellable, verb+noun, honest-count meaning, widget-friendly).
Shortlist: Cairn, Footfall, JustSteps, Treda. All clearance checks TO RUN before release (USPTO/EUIPO/WIPO, domain whois, Play exact search, GitHub handle, web search). No availability claimed.

## Logo brief
Tally-mark stem forming a footstep/cairn stone — honest count, no speed lines. Wordmark + square icon, 16px–1024px legible, monochrome-safe. Must not resemble Stride, Pacer, Google Fit, Samsung Health, Accupedo, Leap (no wings, swooshes, foot-arrows, blue/green gradients).

## Voice — Plain. Steady. Truthful.
Say plainly, not hype. Show the number, don't inflate. Admit limits, don't fake precision. Stay quiet, don't nag. Respect offline, don't beg for login.
